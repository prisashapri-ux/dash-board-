# Дорожная карта Пульта

Цель — личное управление с надёжным хранением данных и поддержкой iPadOS 15.

| Приоритет | Работа | Критерий готовности |
|---|---|---|
| P0 | Актуальность календаря и графика | Ежедневное получение из разрешённых источников, шифрование вне публичного репозитория, видимое время обновления |
| P0 | Личные проекты | Актуальный список экспортирован и проверен на каждом устройстве; публикация личного содержимого прекращена |
| P0 | Синхронизация | Авторизованный защищённый обмен данными, обработка конфликтов, проверка на iPad и iPhone |
| P1 | Резервное копирование | Зашифрованный экспорт, проверка формата, возврат к состоянию до импорта |
| P1 | Управление проектом | Этот реестр, проверка изменений до опубликования, актуальные задачи и критерии |
| P1 | Центр ИИ | Быстрый доступ к сервисам, шаблоны поручений; интеграция только через поддерживаемые авторизованные механизмы |
| P2 | Каналы | Ручная история показателей; автоматическое получение через официальные API после настройки доступа |
| P2 | База знаний | Записи по разделам PARA, поиск и связи с проектами |

## Порядок переноса данных

1. На каждом устройстве открыть настройки, создать защищённую копию, проверить её восстановление на отдельном профиле.
2. Перенести текущие проекты на устройство и отключить публичное обновление. Убедиться, что проекты и задачи остались доступны.
3. Только после подтверждения переноса удалить личное содержимое из публикуемого исходника и решить вопрос сохранённых исторических версий отдельно.
4. Для автоматического обмена выбрать место хранения с авторизацией. До его подключения использовать защищённые файлы копий. Не помещать пароли и незашифрованные данные в репозиторий.

## Интеграции

Для ежедневного сбора календаря и смен нужны авторизованные источники и защищённая конфигурация существующего шифрования. Сценарии сборки календаря и смен уже есть в scripts; передавать в них внешние данные только вне репозитория. Для статистики Twitch и YouTube нужны официальные разрешения API. Ключи не включать в клиентский код.
