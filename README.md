# Пульт

Информационный экран для старого iPad Air 2 (Safari на iPadOS 15, альбомная ориентация 1024×768), который стоит у кровати: утром — задачи и погода, вечером — итоги дня и план на завтра. Так же работает на iPhone в портретной ориентации. Ставится на экран «Домой» и открывается без интернета.

Сервера нет. Все личные данные хранятся в браузере (IndexedDB) на том устройстве, где ими пользуются. Сеть нужна только для погоды и качества воздуха (Open-Meteo), курсов ЦБ и свежего `projects.json`.

## Что умеет

- **Главная.** Крупные часы и дата по-русски, погода для выбранного города: осадки на ближайшие 2 часа, восход и закат, качество воздуха. Режим выбирается по времени (утро 05:00–12:00, вечер 18:00–05:00, иначе день) или вручную переключателем. Утро: задачи на сегодня, следующие шаги трёх главных проектов, утренняя рутина, карточка «Время и цели». День: задачи, сводка по проектам, «Время и цели», курсы ЦБ. Вечер: итоги дня (кольцо выполнения, привычки, траты против дневного бюджета), задачи на завтра, оценка дня 1–5 с двумя вопросами и графиком за 2 недели, вечерняя рутина, быстрые «+ задача» и «+ заметка». В последний день месяца (и года) сверху появляется карточка «Подведи итоги» по целям.
- **Проекты.** Карточки с этапом (Идея, План, В работе, Проверка, Готово), прогрессом, следующим шагом, дедлайном и счётчиком задач. По нажатию открывается окно со всеми задачами, где можно отмечать, добавлять и удалять задачи и менять этап, прогресс, шаг и дедлайн.
- **Задачи.** Личные задачи с датой, временем и привязкой к проекту, группы «Просрочено / Сегодня / Завтра / Неделя / Позже» и полоса из 7 дней с числом задач (пока она заменяет блок «Календарь»).
- **Заметки.** Крупное поле для быстрого ввода (удобно диктовать микрофоном клавиатуры), закрепление, поиск.
- **Новости.** Свежие заголовки по темам: ИИ и Claude, новые ИИ-репозитории на GitHub (за неделю, по звёздам), ИИ-анимация (YouTube-каналы и новости), 3D-печать и ИИ, Сочи, технологии, игры (популярное у стримеров и на YouTube, Dota 2). Одна и та же новость из разных источников показывается один раз. Обычно за двое суток, у игр за 3 дня, у редких тем за неделю. Нажатие открывает статью в Safari. Звёздочка ☆ откладывает новость в «На потом» для подробного изучения: там её можно отметить изученной или удалить, отметки хранятся на устройстве и входят в резервную копию. Любую тему можно убрать из общей ленты. Пять последних новостей видны на главной утром.
- **Смены.** Отдельная вкладка с графиком работы кафе Мими Руш по всем сотрудникам из Google Таблицы. Сверху выбранный день (по умолчанию сегодня, стрелки ◀ ▶): полосы смен на шкале часов с 8 до 23, у каждого сотрудника свой цвет, красная линия — текущее время, ниже кто выходной и кого нет в графике. Дальше таблица месяца: все сотрудники по строкам, в клетке часы смены, справа сумма часов и смен за месяц, снизу сколько человек на смене (меньше двух — красным), нажатие на число открывает этот день. Своя строка подсвечена, внизу «Мои ближайшие смены». На главной карточка: твоя смена сегодня и завтра, следующая смена, кто сегодня в кафе. Если в графике что-то поменялось, появляется «График изменился» (было → стало), пока не нажмёшь «Понятно».
- **Ещё.** Привычки (неделя отметок и серия подряд), рутины (шаги утра и вечера, можно менять порядок), цели на месяц и год и обратные отсчёты, список покупок и меню на неделю, финансы (курсы ЦБ, траты, итоги за день, 7 дней и месяц, месячный бюджет с остатком и дневным лимитом), заглушка для статистики Twitch и YouTube, настройки (город через поиск Open-Meteo, часы режимов, ночная тема, экран, резервная копия, «Обновить проекты», версия).
- **Экран.** Пульт не даёт экрану гаснуть (в Safari 15 нет Wake Lock, поэтому крутится крошечное беззвучное видео; включается после первого касания). После простоя (по умолчанию 5 минут) включается режим «рамки»: крупные часы, дата и погода, которые раз в минуту сдвигаются по экрану, а днём можно показывать свои фото. Касание возвращает Пульт. Ночью поверх всего ложится затемнение (по умолчанию 30%), нажатия оно не перехватывает.
- **Ночная тема.** Тёмно-красная приглушённая палитра, по умолчанию включается сама вечером и ночью.

## Обновления

Пульт обновляется сам, как «Форма»: после пуша в `main` и выкладки сервис-воркер скачивает новую версию в фоне (проверка при каждом возврате на экран и раз в 10 минут, пока Пульт открыт), и страница перезагружается. Если в этот момент открыто окно или в поле набран текст, перезагрузка ждёт, пока ты закончишь. Режим «рамки» после перезагрузки возвращается. В «Ещё → Настройки → Обновления» есть кнопка «Обновить Пульт», чтобы обновить сразу.

## Как устроены данные

- **Проекты** лежат в `src/projects.json`. Их обновляет Claude коммитами, а ты можешь править прямо в приложении. При запуске приложение берёт `projects.json` из сети (если сети нет, из кэша) и сливает с локальными правками по каждому проекту: побеждает тот, у кого `updated` новее. Локальная правка ставит `updated` равным текущему времени. Проекты, которые есть только на устройстве, остаются. Дату последнего обновления `projects.json` видно в «Ещё → Настройки».
- **Всё остальное** (задачи, заметки, привычки, рутины, цели, отсчёты, дневник, покупки, меню, траты, настройки) хранится только на устройстве в IndexedDB. Фото для «рамки» уменьшаются до 1280 px и лежат отдельно, в резервную копию не входят.
- **Резервная копия** JSON: в «Ещё → Настройки» кнопка «Скопировать в буфер», ссылка «Скачать файл» и загрузка из файла. Перед загрузкой текущие данные сохраняются во внутреннюю копию.
- Запросы уходят только на `api.open-meteo.com`, `geocoding-api.open-meteo.com`, `air-quality-api.open-meteo.com`, `wttr.in` (запасная погода), `api.github.com` (лимиты Claude) и `www.cbr-xml-daily.ru` (курсы ЦБ), остальное запрещено политикой безопасности (CSP).
- **График смен** раз в день обновляет Claude по расписанию: читает в Google Таблице «График Мими Руш» лист текущего месяца и следующего («<месяц> <год>», например «ноябрь 2026») и запускает `scripts/make-shifts.mjs`, который собирает и шифрует `data/shifts.json`, затем коммитит его в `main`. Сайт публичный, поэтому график всех сотрудников лежит зашифрованным (PBKDF2 + AES-GCM): без пароля имён и часов не видно. Пароль знает задача Claude, на iPad его вводят один раз во вкладке «Смены», хранится он только на устройстве. Файл не входит в версию сайта, поэтому обновление графика не перезагружает Пульт. Пульт проверяет файл раз в 10 минут. Разбор листа — `parseSchedule` в `src/logic.js`: первое число ищется по строке дней недели, смены вида `9-22`, `Х` — выходной. Часы в таблице Пульта считаются по клеткам смен и могут не совпадать с колонкой «итого» в самой таблице.
- **Новости** собирает GitHub Actions (`scripts/fetch-news.mjs`, в той же выкладке, что и погода, раз в 30 минут) из RSS-лент, YouTube-каналов (по @имени) и поиска GitHub, список — `NEWS_FEEDS` в `src/logic.js`. Результат лежит в `data/news.json` на сайте Пульта, поэтому iPad не ходит на новостные сайты сам и VPN не нужен (нужен только чтобы открыть саму статью, если сайт без него не открывается). Лента, которая не ответила, пропускается; что ответило, видно в логе выкладки и в поле `feeds` файла.
- **Погода без VPN.** Если Open-Meteo из сети iPad не открывается (так бывает без VPN), Пульт берёт погоду с собственного сайта: `data/weather.json`. Её каждые 30 минут кладёт туда GitHub Actions (`scripts/fetch-weather.mjs`, расписание в `pages.yml`) для города по умолчанию (`DEFAULT_SETTINGS` в `src/logic.js`). Для другого города или если файл старше 3 часов этот запасной путь не используется. Файл не входит в версию сайта, поэтому выкладка погоды не перезагружает Пульт. GitHub отключает расписание, если в репозитории 60 дней не было коммитов.


## Разработка

```
npm test        # тесты логики (node:test), зависимости не нужны
npm run build   # собирает сайт в dist/ с версионным service worker
npm run icons   # перерисовывает иконки в icons/
```

`dist/` можно открыть любым статическим сервером, например `python3 -m http.server -d dist`. Публикация на GitHub Pages идёт по пушу в `main`: тесты, сборка, выкладка (`.github/workflows/pages.yml`). Сторонних пакетов нет, поэтому `npm ci` в workflow не нужен.

Код: `src/logic.js` — чистые функции (слияние проектов, режимы, группировка задач, итоги, привычки, финансы, погода) с тестами в `test/logic.test.mjs`; `src/store.js` — хранение; `src/app.js` — интерфейс. Совместимость с Safari 15: без CSS nesting, `:has()`, blur, `Array.at` и подобного, шрифты от 13px, кнопки от 44px.

## Как Claude обновляет проекты

Claude правит `src/projects.json` (этап, прогресс, следующий шаг, задачи) и ставит в изменённом проекте `updated` с текущей датой и временем в формате ISO, например `2026-11-12T12:00:00Z`. Если правка нужна поверх локальной, `updated` должен быть новее локального. После коммита и пуша в `main` страница пересобирается, и при следующем запуске iPad подтягивает свежий файл (или по кнопке «Обновить проекты»).

## Лимиты Claude

На главной есть плашки «Текущая сессия» и «Все модели за неделю», как в настройках Claude. Официального способа прочитать их из браузера нет, поэтому цифры идут так: Claude Code на ПК передаёт лимиты своей строке состояния, скрипт `tools/pult-usage.ps1` пишет их в гист GitHub, а Пульт раз в 2 минуты читает этот гист. Лимиты общие для аккаунта, но обновляются, только пока на ПК работает Claude Code.

Настройка на Windows-ПК один раз:

1. Создай гист на gist.github.com: файл `claude-usage.json`, содержимое `{}`, «Create secret gist». Скопируй ID из адреса (часть после имени пользователя).
2. Создай токен: github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, галочка только `gist`.
3. Скачай `tools/pult-usage.ps1`, например в `C:\Users\<имя>\pult-usage.ps1`.
4. В PowerShell: `setx PULT_GIST_ID "<ID гиста>"` и `setx PULT_GIST_TOKEN "<токен>"`, потом перезапусти Claude Code.
5. В `C:\Users\<имя>\.claude\settings.json` добавь:
   `"statusLine": { "type": "command", "command": "powershell -NoProfile -ExecutionPolicy Bypass -File C:\\Users\\<имя>\\pult-usage.ps1" }`
6. В Пульте: Ещё → Настройки → «Лимиты Claude» → вставь ID гиста.

Токен хранится только на ПК. В Пульт и в гист попадают только проценты и время сброса.
